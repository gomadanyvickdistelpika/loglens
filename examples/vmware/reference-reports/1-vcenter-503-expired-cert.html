Expired / invalid vCenter and ESXi certificates: KB 344201 Error: "no healthy upstream" or "503 Service Unavailable" when accessing vCenter Server (verify and resolve expired vCenter certificates); KB 413685 vSphere Client reports "no healthy upstream" due to expired certificates; KB 396907 Machine SSL certificate replacement and auto-renewal in vCenter Server 8.x; KB 440277 vCenter certificate replacement fails at 85% with rollback using certificate-manager
Cause: MACHINE_SSL, STS or Solution User certificate (or an issuer) is past its validity.
  1. Confirm expiry: list each VECS store with vecs-cli and read the Not After dates.
  2. Replace with vCert.py (Option 3 Manage certificates > Option 1 Machine SSL, VMCA-signed) or Certificate Manager; take a snapshot first (all nodes in Enhanced Linked Mode); restart services.
  3. ESXi host cert: Configure > Certificates > Renew; for HA clusters set vpxd.certmgmt.mode=vmca.
  4. vCenter 8.0 U3h+ with vpxd.certmgmt.mode=vmca renews Machine SSL automatically 5 days before expiry.
  5. If replacement fails at 85%, check the PNID vs certificate FQDN (case-sensitive). A thumbprint mismatch with no expiry can be an SSL-inspecting firewall.
